# 🌐 Personal Portfolio Website — WordPress Project

> A personal portfolio website built with WordPress as part of the **Web Services Design** laboratory project at **Politechnika Bydgoska** (Faculty of Telecommunications, Computer Science and Electrical Engineering).

---

## 📌 Project Overview

This website serves as a personal portfolio to introduce myself, showcase my projects, and provide a way for visitors to get in touch. It was built using **WordPress** running on a local environment via **Local WP**.

The site is connected to my personal interests and field of study, demonstrating various WordPress features including custom themes, posts, categories, tags, forms, and navigation.

## 🚀 How to Run Locally

1. Install [Local WP](https://localwp.com)
2. Clone or download this repository
3. Import the site into Local WP
4. Start the site and click **WP Admin**
5. Login with your credentials
